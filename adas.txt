Course Title    Analysis and Design of Algorithms
Course Description :

Course Objectives :
SN.    Objectives
1    Build a strong foundation in algorithm design, analysis, computational complexity, and performance evaluation.
2    Introduce algorithm design techniques for developing efficient solutions for a variety of computational problems.
3    Develop skills to analyse, compare, and implement algorithms for graph, optimization, and decision-making problems.
4    Enable students to evaluate the efficiency of algorithm and develop the ability to design efficient algorithms for solving real-world computational problems.

Course Contents / Syllabus :
SN.    Module    Descriptors / Topics    Weightage
1    Introduction    Algorithm Design paradigms - motivation, concept of algorithmic efficiency, run time analysis of algorithms, Asymptotic Notations. Recurrences- substitution method, change of variable, recursion tree method, master method    20.00
2    Divide and Conquer    Structure of divide-and-conquer algorithms: examples; Binary search, quick sort, Merge sort, Heapsort, Strassen matrix multiplication; Run time analysis of divide and conquer and recurrence relations. Greedy Method: Overview of the greedy paradigm examples of exact optimization solution (minimum cost spanning tree), approximate solution (Knapsack problem), Single source shortest paths problems-Bellman Ford and Dijkstra’s Algorithm, traveling salesman problem    20.00
3    Dynamic Programming    Overview, difference between dynamic programming and divide and conquer technique, Applications: Shortest path in graph, chain matrix multiplication, Traveling salesman Problem, longest Common sequence problem, knapsack problem    20.00
4    Graph Searching and Traversal    Overview, Representation of graphs, strongly connected components, Traversal methods (depth first and breadth first search) and its analysis Back tracking: Overview, 8-queen problem, and Knapsack problem Brach and bound: LC searching Bounding, FIFO branch and bound, LC branch and bound application: 0/1 Knapsack problem, Traveling Salesman Problem    25.00
5    Computation Complexity    Complexity measures, Polynomial Vs non-polynomial time complexity; NP-hard and NP-complete classes, examples, Proving NP-Complete problems: 3CNF SAT, CLIQUE, Vertex-Cover, TSP and Hamiltonian Cycle problem    15.00

Course Learning Outcomes :
SN.    Course Learning Outcomes
1    Analyze the time and space complexity of algorithms using asymptotic notations and recurrence relations to determine their computational efficiency.
2    Design and develop efficient algorithms using Divide-and-Conquer, Greedy, Dynamic Programming, Backtracking, and Branch-and-Bound paradigms to solve computational problems.
3    Apply graph algorithms and optimization techniques to solve problems involving graph traversal, shortest paths, minimum spanning trees, and combinatorial optimization.
4    Evaluate and compare different algorithmic approaches to select the most appropriate solution based on correctness, efficiency, and computational complexity
5    Evaluate computational problems by classifying them into P, NP, NP-Hard, and NP-Complete categories and determine the feasibility of algorithmic solutions for real-world applications.
